# HR-аналитика: «Работа с заботой»

## Постановка задачи

Заказчик — **HR-отдел компании «Работа с заботой»**. Необходимо разработать две модели машинного обучения, которые помогут HR-специалистам принимать обоснованные решения:

- **Модель регрессии** — прогноз уровня удовлетворённости сотрудника (целевой признак: `job_satisfaction_rate`)
- **Модель классификации** — прогноз вероятности увольнения сотрудника (целевой признак: `quit`)

### Критерии качества моделей

| Задача | Метрика | Порог |
|--------|---------|-------|
| Регрессия (удовлетворённость) | SMAPE | ≤ 15% |
| Классификация (увольнение) | ROC-AUC | ≥ 0.91 |

## Данные

| Файл | Описание |
|------|----------|
| `train_job_satisfaction_rate.csv` | Обучающая выборка для задачи 1 (с целевым признаком) |
| `train_quit.csv` | Обучающая выборка для задачи 2 (с целевым признаком) |
| `test_features.csv` | Тестовые признаки (для обеих задач) |
| `test_target_job_satisfaction_rate.csv` | Тестовые целевые значения для задачи 1 |
| `test_target_quit.csv` | Тестовые целевые значения для задачи 2 |

### Признаки

| Признак | Тип | Описание |
|---------|-----|----------|
| `id` | int | Идентификатор сотрудника (технический) |
| `dept` | категориальный | Отдел |
| `level` | порядковый | Уровень должности |
| `workload` | порядковый | Уровень загруженности |
| `employment_years` | числовой | Стаж работы в компании (лет) |
| `last_year_promo` | бинарный | Было ли повышение в прошлом году |
| `last_year_violations` | бинарный | Были ли нарушения в прошлом году |
| `supervisor_evaluation` | числовой | Оценка руководителя |
| `salary` | числовой | Уровень зарплаты |

## Этапы работы

### Задача 1: прогноз `job_satisfaction_rate`

1. **Загрузка и предобработка данных**
   - Изучение типов и распределений признаков
   - Работа с пропусками через пайплайн (импутация)
2. **EDA**
   - Распределение целевого признака
   - Корреляции числовых признаков
   - Анализ категориальных признаков
3. **Построение пайплайна**
   - `OneHotEncoder` для номинальных категорий
   - `SimpleImputer` для пропусков
4. **Обучение моделей и подбор гиперпараметров**
   - Ridge Regression
   - Decision Tree Regressor
   - GridSearchCV по SMAPE
5. **Итог:** лучшая модель достигает **SMAPE ≤ 15%**

### Задача 2: прогноз `quit`

1. **Предобработка**
   - Кодирование целевого признака: `yes/no → 1/0`
2. **EDA**
   - Анализ баланса классов
   - «Портрет уволившегося» сотрудника
   - Сравнение распределений train/test
   - Гипотеза: влияние `job_satisfaction_rate` на `quit`
3. **Feature Engineering**
   - Добавление нового признака `job_satisfaction_rate_pred` из лучшей модели задачи 1
4. **Обучение моделей**
   - Logistic Regression (подбор `C`)
   - Decision Tree Classifier
   - Random Forest Classifier
   - GridSearchCV по ROC-AUC
5. **Итог:** лучшая модель достигает **ROC-AUC ≥ 0.91**

## Ключевые выводы

- Уровень удовлетворённости поддаётся прогнозу с точностью SMAPE < 15% на основе структурных признаков сотрудника
- Прогноз удовлетворённости (`job_satisfaction_rate_pred`), добавленный как признак во вторую задачу, улучшает качество классификации увольнений
- Дерево решений / случайный лес показывают лучшую ROC-AUC на задаче классификации
- Нарушения, низкая оценка руководителя и низкая зарплата — наиболее значимые предикторы увольнения
